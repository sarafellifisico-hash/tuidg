# Continuidade e recuperação do TUIDG

## Cópias principais

1. **GitHub** — fonte oficial do código e histórico de versões.
2. **Cloudflare Pages** — publicação automática do site.
3. **Backup ZIP local** — cópia de emergência em computador e nuvem.
4. **ChatGPT Site atual** — manter ativo até a versão independente ser conferida e aprovada.

## Fluxo seguro de atualização

1. Criar uma alteração em uma cópia ou ramificação.
2. Testar a página inicial, navegação, páginas da teoria e simulador.
3. Registrar a alteração no GitHub com uma mensagem clara.
4. Conferir a implantação de teste no Cloudflare.
5. Somente depois considerar a versão aprovada.

## Recuperação

Em caso de perda do computador ou do aplicativo:

1. Baixar o repositório do GitHub.
2. Abrir `index.html` ou publicar novamente no Cloudflare.
3. Restaurar o simulador a partir do repositório próprio, se necessário.
