# TUIDG — Immaterial Geometry

Independent static source copy, prepared for GitHub and Cloudflare deployment.

## Contents

- `index.html` — main page
- `theory/` — 32 standalone theory pages
- `assets/site.css` — visual styles
- `assets/site.js` — local interactions and smooth navigation
- `assets/favicon.svg` — site icon
- `CONTINUIDADE.md` — recovery and maintenance instructions
- `AUDITORIA_TECNICA.md` — technical verification record

## Run locally

Open `index.html` in a modern browser, or serve the folder with a simple local web server.

## Deployment

This is a static website. No build command is required. For Cloudflare Pages, publish the repository root.

## Important dependency

The Meronic Simulator is embedded from:

`https://sarafellifisico-hash.github.io/Merons/`

The main site remains usable without it, but the embedded simulator needs that external address to remain available.

## Source status

This export contains 33 HTML pages. Most theory chapters are concise editorial summaries that link to the legacy Google Sites pages for the complete long-form text and illustrations. It is therefore an independent working copy, but not yet a full migration of every legacy chapter and visual asset.
